# Magpienest Store

English | [繁體中文](README.zh-TW.md)

Optional features for [Magpienest](https://github.com/ddd000987/Magpienest). Install them inside the app:
Settings → Plugin store.

This repository holds only the store list (`catalog.json`) and the packages in
its releases. Both are generated by `build/publish.ps1` in the main repository;
nothing here is edited by hand.
